# 远征手记 · Expedition Journal

面向长期西征团的共享地图、角色日记与物品管理工具，计划支持独立网页和 Owlbear Rodeo 扩展入口。

> 当前状态：项目建档 / 需求设计。尚无可运行应用、多人服务或已发布的 Owlbear 扩展。

## 产品方向

- 每个战役拥有独立页面、成员、角色、地图、日记和公共仓库，支持多个团。
- 玩家通过简单登记板输入角色姓名，并能继续创建其他角色。
- 导入地图、放置标注，点开阅读关联角色的日记。
- 日记以自由正文为中心，自动记录作者和实际写入时间；支持冒险时间与写入顺序两种排序。
- 角色背包和战役公库以文本物品为主，支持存入、取出和转交。
- 主要服务电脑、iPad 与华为平板；照顾触屏、键盘、横竖屏与分屏使用。
- 以 14—16 世纪成熟彩饰手抄本、尤其时祷书为美术参考。
- 提供可阅读的文档导出和可恢复的完整数据备份。

## 开发状态

本仓库先记录可实施的需求和关键约束。后续依次验证交互样稿、多人数据、地图日记、物品流转、Owlbear 接入与导出。README 中的目标不代表已经实现。

当前未固定技术栈和托管平台；项目应能够独立部署，并为其他团复用。公开源码不意味着战役数据公开。实际团录、玩家信息、地图上传与访问凭据不进入代码仓库。
