# 远征手记 · Expedition Journal

面向长期西征团的地图、角色日记与物品管理工具。以 14—16 世纪彩饰手抄本、尤其时祷书为美术参考。

**当前状态：v0.2，共享房间与本机独用均可运行。** 已实现房间邀请、多人同步、服务器持久化、地图绘图和物品图片。尚未选择公网托管地址；Owlbear 扩展和独立身份权限仍待实现。

## 立即运行

需要 Node.js 22 或更新版本。在项目目录执行：

```sh
npm run serve
```

打开 http://127.0.0.1:4173 。无需安装依赖或构建。不要直接双击 HTML 文件。

启动后，选定远征，点击“共用”创建共享副本，再把“邀请同伴”里的链接交给同伴。同伴加入后登记或选择自己的角色。不同窗口/设备需要访问**同一个服务地址**；127.0.0.1 只指向当前电脑。公开上线地址稍后选择。

数据默认保存在项目的 `data/`，已从 Git 排除。可用 `HOST`、`PORT`、`DATA_DIR` 环境变量修改监听地址、端口和持久化目录，详见 [共享房间与运行说明](docs/shared-rooms.md)。静态托管 `dist/` 仍可独用，但不能运行共享房间。

## 已实现

- 多个独立远征，姓名登记与角色切换；圆形头像裁剪，拖动、缩放与键盘调整。
- 左页日记、右页满幅地图；物品册左页行囊、右页公库。彩饰首字母导航与翻页动画；装饰让出正文和操作区域，尊重减少动态效果设置。
- 鼠标右键/中键拖动地图，滚轮围绕指针缩放，左键点击空白处直接落标。地点标签显示参与者的头像和名字，点击就近展开竖向卷轴。方向键移动，＋/− 缩放，0 查看全图。
- 平板单指浏览、双指缩放；先点“标注”再落标。已实现触控分支，仍待真实 iPad / 华为平板验收。
- 蘸水笔自由绘图，墨黑、朱红、青金石、草绿四种墨色，三种笔宽；可以撤去自己上一笔。也可上传圆形/方形贴图，放置、移动、缩放和移除。
- 日记自由正文、自动保存、角色署名、实际写入时间、冒险日期与日序；按冒险时间或写入顺序排列，作者筛选、正文和回复搜索。
- 手记回复与补充仍属原篇，不增加篇数或改变原篇排序。地图卷轴显示同一份内容，空地点也可先留言。
- 文本物品、数量与说明；新物品和已有物品均可添图，每件最多 8 张，圆形/方形裁剪，点击看大图。整份或拆分存入、领取和转交，图片随物品保留，出入记录及撤销。
- 共享房间同步手记、回复、头像、地图、笔迹、贴图和各角色的物品图片。同伴可切换角色查看相应行囊。
- 不同条目和不同字段的修改合并；同一字段的同时修改暂停并保留本机待同步内容。公库竞争领取不能把同一份数量领两次。已保存的笔迹、图片与文字在服务重启后保留。
- 已加入房间的文字修改先留存在本机待发送队列，重连后继续同步；图片上传需要服务可连接。遇到差异可导出自己的副本或采用房间版本。
- 当前远征 Markdown、可打印 HTML 文字阅读版；包含全部远征、回复、头像、上传图片与笔迹的完整 JSON 备份。邀请凭据不进入备份；恢复为独用副本，不覆盖服务器房间。
- 可选浏览器 WebMCP：读取当前远征索引、翻开已有手记。不支持时不影响使用。

## 装帧

书页使用以沃尔特斯 W.183《时祷书》空白犊皮纸页为参考生成的暖象牙色纸纹，置于绘画式斜板书桌。原扫描仍保留作研究素材。

非地图页以蓝色上下沿、红色竖沿、双侧包金和深色墨线围合；上角素面、下角方框圆徽。地图叶保持满页。蓝色手记题栏、绿色地点栏、不同颜色的物品题栏，以及完整的书记员、鸟兽、旅人、守库小画共同划分内容。编辑与标注采用火漆，全图采用罗盘，绘图采用蘸水笔；小动作沿用墨色字和细花饰。

本轮统一整理了新工具、表单、裁剪、图片册和导出菜单：减少重复实色按钮与空泛短句，保留有用途的提示。对话纸页采用朱红题字、金框首字和蓝色横栏，填空区保持清楚。

## 数据与边界

独用文字、回复和头像保存在浏览器 localStorage；上传图片保存在 IndexedDB。共享房间的权威副本在服务器 `data/`，浏览器保留缓存和待发送队列。清理浏览器数据可能丢失尚未同步的修改；请定期导出完整备份。阅读版不能用于恢复。

角色名册是团内共同署名方式，**不是身份验证**。持有邀请链接的人可以共同编辑和切换角色，暂无 GM / PL 分级权限、成员撤权或邀请轮换。代码未公开房间数据；运行目录、实际团录和凭据均不进入仓库。

单张地图最多 12 MB / 8000 万像素；裁剪输入最多 12 MB / 4000 万像素。头像为 256×256，物品及贴图为 512×512。每处最多 500 条回复、每条 10000 字；每张笔迹最多 2000 个采样点。房间图片总上限 160 MB，包含仍保留的旧上传；备份导入最多 100 MB。更大房间的备份拆分和图片回收尚未实现。

还没有离线安装、Owlbear 接入、真实平板硬件认证或公网部署。房间邀请能力和多人窗口已验收，不能据此宣称拥有独立账户权限。

## 开发与文档

```sh
npm test
npm run check
```

`dist/app.js` 为界面，`domain.js` 为数据规则；`map-camera.js` / `map-view.js` 为地图几何和手势，`media-domain.js` 为笔迹与附图校验；`server.js`、`room-client.js`、`shared-merge.js` 实现共享服务、持久化队列和合并。`avatar-crop.js` 供头像和圆/方附图共用。

localhost `?qa=alice12`、`?qa=bob12` 使用不同文字存储键，方便同服务双玩家验收，不混入正常团录。
