# 远征手记 · Expedition Journal

面向长期西征团的地图、角色日记与物品管理工具。以 14—16 世纪彩饰手抄本、尤其时祷书为美术参考。

**当前状态：v0.1 可操作的本机交互样稿。** 已能登记角色、导入地图、写日记、管理行囊与公库、导出及恢复备份。多人同步、邀请与权限、Owlbear 扩展尚未实现，不能作为多人共享服务使用。

## 立即运行

需要 Python 3。在项目目录执行：

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4173 。不要直接双击 HTML 文件；浏览器模块和本地存储需要 HTTP 环境。没有第三方 JavaScript 运行依赖，不需要安装或构建。可将 dist 内容放到任意静态托管服务。

## 已实现

- 多个独立战役；名字登记与角色切换，每个角色有自己的行囊。
- PNG、JPG、WebP 地图导入，地图缩放、标注及地点日记；标注可更名、移动和移除。
- 自由正文、自动保存、角色署名、实际写入时间、冒险日期与日序。
- 按冒险时间或写入顺序排列，作者筛选、正文搜索。
- 文本物品、数量和说明，拆分或整份存入公库、领取及转交；出入记录和撤销。
- 当前战役 Markdown、可打印 HTML；包含所有战役和上传图片的 JSON 备份及恢复。
- 电脑双栏、平板竖屏布局；键盘输入、原生对话框和触屏按钮。
- 可选浏览器 WebMCP：读取当前战役索引与翻开已存在的日记。浏览器不支持时不影响使用。

## 数据与边界

文字存在当前浏览器的 localStorage，地图存在 IndexedDB。**换浏览器、换网址或换设备不会自动同步。** 清理网站数据会删除这些内容，请定期导出完整备份；阅读版不能用于恢复。恢复会替换本设备全部战役，界面会先提示。

单张地图最多 12 MB、8000 万像素；备份导入最多 100 MB。浏览器存储配额因设备而异。遇到保存失败会明确提示，仍可导出当前草稿的备份。同设备多窗口更新时，正在编辑的窗口会暂停覆盖并提示处理冲突。

角色名册目前不是身份验证，任何本机使用者都能切换角色和修改日记。公库在这一版是本机演示，尚无网络并发交易保障。此版本未提供离线安装，也未在真实 iPad Safari / 华为浏览器上完成验收。

公开源码与设备上的战役数据分开；实际团录、玩家资料、上传地图和凭据不进入代码仓库。演示文字仅讲解操作，不代表卡塔尼亚的世界设定。
