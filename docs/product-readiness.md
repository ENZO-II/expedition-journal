# 公开试用前的产品准备

当前版本面向邀请制的西征团共同记录。基础写作、物品与多人同步已经实现，正式公开运营还需按使用规模验证运行条件。

## 已具备

首次使用可以新建远征、加入共享或试读演示；同一远征的私有/共享版本收在一条名册中。既有内容分别保存，同名远征不会直接合并。完整备份保留分组信息，恢复副本仍能单独打开。

保存失败会持续显示，连接中断保留本机待发送修改，重连和同步差异在页底有可操作入口。旧表单与后台更新的冲突会保留自己的内容；物品竞争领取经过数据规则和实际服务测试。

Owlbear 提供可添加的 JSON 清单和房间绑定入口。网站、扩展和共享 API 同源运行；外部依赖已固定版本并保留许可。源码与运行数据分离，实际房间、邀请凭据和玩家图片不进入公开仓库。

## 正式团用前

- 确定所有玩家可访问的 HTTPS 地址，持久化数据目录、备份/恢复流程和进程重启方式；验证代理下的事件长连接与图片上传。
- 在真实 iPad Safari 与华为平板验证双指地图、头像裁剪、软键盘、全屏扩展及长期存储；桌面窄窗口不能替代实机。
- 根据公开范围决定账户、角色所有权、主持人权限、邀请轮换和成员撤权。当前邀请制的共同编辑不能描述为完整身份权限系统。
- 补充公网建房限流、磁盘告警、错误监控和较大房间性能记录；规划旧图片回收及大备份拆分。

当前接入先完成房间手记入口；场景标注互通另有明确开发范围。功能说明以实际验收记录为准，不将本机两窗口通过视为公网或真实平板通过。
