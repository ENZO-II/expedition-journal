# 手抄本参考与素材来源

## 美术方向

14—16 世纪成熟彩饰手抄本，以时祷书为主要参考。选一本为主参考，补充同时期或风格相近素材。分别研究开篇彩饰页、日常文字页、边饰与小画；不只研究封面。

## 素材入库规则

每张实际使用的图像登记：馆藏机构、作品名、作者、年代、馆藏号、叶码（如有）、原始页面、原图链接、许可链接、获取日期、本地文件与修改方式。

代码的 MIT 许可不覆盖第三方素材；字体、地图、图像分别核对。只采用允许项目预期使用和分发方式的素材。保留馆藏说明与出处，不把模型生成图像冒充历史原件。


## 空白犊皮纸页 · 2026-10-01

采用 [Walters W.183《时祷书》126v](https://www.thedigitalwalters.org/Data/WaltersManuscripts/html/W183/description.html)，约 1460–1470 年，布鲁日。馆藏说明确认 126–131 叶是中世纪原抄本的空白尾页，并说明承载材料为犊皮纸。保留摄影纹理与淡红界栏，CSS 调暖以改善屏幕阅读；不把新做的界面装帧说成原作。

数字沃尔特斯当前 [开放说明](https://www.thedigitalwalters.org/01_ACCESS_WALTERS_MANUSCRIPTS.html) 明确将图像与数据以 CC0 发布。当前书页纹理只使用这一张原图；旧版裁切 Bening 边饰的做法不再使用。
