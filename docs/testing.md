Node 原生测试共 6 项通过：两种日记排序、编辑不改变写入顺序、物品拆分与整份交付数量守恒、非法交付不修改数据、JSON 往返、损坏备份拒绝与文本 HTML 转义（部分组合为同一测试项）。app.js 与 domain.js 语法检查通过。

## 浏览器实际操作

- 创建“验收远征”，登记“试写旅人”，与演示战役分开。
- 输入正文、完成书写、刷新后从手记目录读回；作者和写入时间存在。
- 导入 JPG 地图、点击落下标注、直接写地点日记。
- 新增干粮 6 份，拆分 2 份存入公库，观察行囊 4、公库 2。
- 导出包含两个战役和上传图片的完整 JSON（约 4.7 MB），通过界面导入恢复，刷新后地点日记、地图和公库数量存在。
- 两种排序观察符合演示文案；WebMCP 读取与翻页成功，无效条目被拒绝。
- 768×1024 竖屏为单栏，无页面横向溢出；1024×768 横屏检查地图和书页。
- 样稿公开源码不包含验收数据或导出的备份。

- 11 项 Node 测试通过：原有 6 项，加上全图适配、指针锚点缩放、拖拽与标注坐标一致、平移和缩放边界、窗口变化时的地图中心计算 5 项。四个 JavaScript 模块语法检查通过。

- 实际点击地图标注，左页展开相应记录；导入过的竖幅地图正确读取 IndexedDB 图片并完整显示。
- 编辑正文时点缩放，再切去物品页，回到地图仍显示改后正文、原作者与创建顺序；刷新后重新点击地点，正文读回成功。同一会话中地图 125% 的浏览状态随章节切换保留。
